# Personal Website

This repository contains the content of my personal website. This website differs from my [portfolio website](https://daniel.bruwel.com) in that it is far less polished. My portfolio website aims to be a professional site that is well written, clean, and shows off my professional skills to employees, professional colleagues, etc. This website is for more miscellaneous things, is far more casual, and is far less polished. To a large extent, I've written it for my own benifite: to organise ideas, write things down so that I'm accountable, etc. However, I suppose it is also written, in some sense, for me to show off all the things that I can't put down on a portfolio, and to mess around with friends and have a bit more fun.

The website is written mostly in HTML, I've chosen to do this because its light weight, easy to edit, and I don't need anything fancy.

I intend to include passion projects, informal rants, writing about stuff that I'm studying, cool things I learned, and other such stuff.
